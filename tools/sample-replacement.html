替换页

A page borrowed from a different document.
PAGE REPLACEMENT DEMONSTRATION

This page can replace another.

这是一份独立的替换页样本。它来自另一份 PDF，在 Folio 中被选中并替换到当前文档的指定页面。原有页面的尺寸、顺序和其他页面都不会改变。

This page is sourced from a separate PDF. In Folio it can be chosen in the page-replacement picker and placed into the current document without disturbing the remaining pages.

替换之后仍然可以编辑文字

页面替换完成后，Folio 会重新读取这一页的文本层。字体、颜色和字重会再次从上下文中提取，自动换行和单页压缩同样有效。

01

选择替换页

打开另一份 PDF，从缩略图中选择任意一页。

02

保留版式

默认保持当前页面尺寸，将新内容等比居中。

03

继续编辑

替换页上的文字块仍然可以被识别与修改。

备选页

A quieter alternative for the same slot.
ALTERNATE PAGE

Second page, second option.

如果第一页不合适，可以选择这份文档的第二页。替换页的文字层同样会被解析，颜色和字重会被重新识别。

If the first option is not the right fit, the second page can be used instead. Its text layer is parsed in exactly the same way.

页面尺寸可以切换

替换时取消“保持当前页面尺寸”，便会采用来源页自身的尺寸。适合将 A4 文档中的某一页替换为横向或 Letter 页面。

A

保持原尺寸

内容等比缩放，四周留白。

B

采用新尺寸

页面随来源页改变，其余页不变。

C

随时撤销

替换操作进入历史记录，可一键还原。
